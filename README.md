# Crystal Hotels Assistant — Azure AI Foundry

A practical AI agent experiment focused on **hotel-information question answering**, document grounding, prompt engineering, safety instructions, and manual evaluation.

## What this project covers
- Creating and configuring the Crystal Hotels Assistant agent in Azure AI Foundry
- Attaching a hotel information document as knowledge base for retrival
- Testing few guest scenarios for accuracy, citations, and safe fallbacks
- Iterating on configuration based on observed behavior
